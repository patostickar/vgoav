DROP-IN POSTER ART — Loop World Tour warp room
================================================

Each portal billboard shows a real image if you drop one here.
Filename must match the region id (any of .jpg / .png / .jpeg / .webp):

    assets/posters/argentina.jpg     ← e.g. a Maradona / football photo
    assets/posters/rome.jpg          ← e.g. the Colosseum
    assets/posters/denmark.jpg       ← e.g. a fjord / longship
    assets/posters/sardegna.jpg      ← e.g. boss / Nuragic art

• Best results: landscape images around 880×304 (a ~2.9:1 window).
  Other sizes are auto-cropped to "cover" the art window.
• No file present? The billboard falls back to its themed emblem
  placeholder (the "10", "S·P·Q·R", runes, "IV").
• Drop a file in and reload — that's it, no code changes needed.
